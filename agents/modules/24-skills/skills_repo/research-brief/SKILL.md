# Research Brief Skill

When the user asks for research, produce a brief with:

1. **Question** — one sentence
2. **Scope** — in/out of scope bullets
3. **Success criteria** — how we know we are done
4. **Open questions** — unknowns to resolve

Keep the brief under 200 words. Do not invent sources.
